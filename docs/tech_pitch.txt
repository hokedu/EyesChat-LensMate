# EyesChat-LensMate 技术逻辑口播文案

浏览器打开摄像头后，每 600 毫秒用 Canvas 截取一帧 320x240 的画面，转成 JPEG base64 通过 WebSocket 发给后端。同时 Web Speech API 在浏览器端做语音识别，识别出中文文本后，自动通过同一条 WebSocket 连接发给服务器。

后端收到"帧数据"和"语音文本"后，把它们组装成一条多模态消息——包含系统提示词、最近五轮对话历史、当前摄像头画面和用户说的话，然后调用 Qwen VL 视觉大模型做流式推理。AI 的回复逐字推回前端，前端实时显示文字，同时调用浏览器自带的 SpeechSynthesis 朗读出来。

整个链路里，语音识别在浏览器端完成，不花一分钱；摄像头只传低分辨率稀疏帧，不是全量视频流；对话历史只保留最近五轮防止 Token 膨胀；AI 回复限制在 200 Token 以内避免长篇大论。最终做到——视觉对话体验完整，但单次请求成本接近于零。
