# Qiniu EyesChat-LensMate — AI 视觉对话助手 最优方案

> 本文档融合了两套方案的优点，形成可直接用于七牛云面试答辩的最终方案。

## 对比分析：两套方案的优势互补

| 对比维度 | EyesChat 方案（已实现） | LensMate 方案（文档） | 最优方案选择 |
|---------|----------------------|---------------------|------------|
| **前端语音识别** | Web Speech API（免费端上） | 后端 VAD + STT（云端成本高） | ✅ EyesChat：零成本，低延迟 |
| **帧采样策略** | 固定 2fps，320×240，JPEG 0.6 | 关键帧 + 画面变化检测 | ✅ LensMate：更智能，避免冗余帧 |
| **场景摘要** | 无 | 每帧提取场景摘要存入短期记忆 | ✅ LensMate：多轮引用更准 |
| **TTS 语音回复** | 未实现（仅文本） | 后端 TTS 转语音播放 | ✅ LensMate：完整语音闭环 |
| **成本仪表盘** | 实时 Token + 费用 + 预算进度条 | 仅文本描述 | ✅ EyesChat：可视化更好 |
| **隐私模式** | 无 | 不保存画面和录音 + 本地模糊 | ✅ LensMate：业务级考虑 |
| **多轮上下文** | 最近 20 轮文本 | 场景摘要 + 对话上下文 + 帧描述 | ✅ LensMate：结构化更强 |
| **弱网降级** | 无 | 自动降低帧率和分辨率 | ✅ LensMate：工程化更强 |
| **云存储集成** | 无 | 七牛 Kodo + CDN + 生命周期 | ✅ LensMate：七牛特色 |
| **VAD 语音检测** | 无（Web Speech 自带静音检测） | 端侧 VAD 判断是否说话 | ✅ EyesChat：Web Speech 已包含 |
| **AI 主动要求调整** | 无 | 画面不清时提示用户靠近 | ✅ LensMate：体验更好 |
| **用户打断** | 无（发送后才可继续说话） | 支持语音打断 AI 回复 | ✅ LensMate：交互更自然 |

## 功能模块对比与合并

### 1. 语音交互 — 融合 EyesChat 的低成本 + LensMate 的完整闭环

| 功能 | EyesChat | LensMate | 最佳选择 |
|------|---------|----------|---------|
| 语音识别 | Web Speech API（免费端上） | 后端 STT（Whisper） | **双模式**：默认 Web Speech（免费），网络差时切换后端 STT |
| VAD 检测 | Web Speech 自带静音检测 | 端侧 VAD | Web Speech 已满足 |
| TTS 回复 | ❌ 无 | 后端 TTS | **OpenAI TTS / Edge TTS**，流式返回播放 |
| 用户打断 | ❌ 无 | 支持打断 | **WebSocket 中断信号 + 前端 AudioContext 停止播放** |

**最优方案**：
- 默认使用 **Web Speech API** 做端上语音识别（零成本）
- 首次发送文本后，后端并行触发 **GPT-4o Vision** 和 **TTS**
- AI 回复以语音形式播放，同时滚动显示文字
- 用户再次说话时，前端自动中断当前 TTS 播放

### 2. 视觉帧采样 — EyesChat 的工程实现 + LensMate 的智能策略

| 策略 | 说明 |
|------|------|
| **基准帧率** | 2fps（每 600ms），平衡实时性和成本 |
| **变化检测** | Canvas 像素差异 > 15% 才上传，静止场景大幅降频 |
| **弱网降级** | navigator.connection 检测 → 差时降至 480p + 0.5fps + JPEG 0.4 |
| **场景摘要** | 后端每 5 帧生成一次简短场景描述，存入短期记忆 |
| **帧留存** | 后端保留最近 3 帧，用于回溯提问（"刚才那个红色物体在哪？"） |

### 3. 多轮上下文 — LensMate 的结构化更优

```json
{
  "user_text": "刚才那个红色工具是什么？",
  "scene_summary": "桌面上有白色路由器、几根黑色网线、一个红色工具",
  "recent_frames": [frame1, frame2, frame3],
  "conversation_history": [
    {"role": "user", "content": "帮我看看桌上有什么"},
    {"role": "assistant", "content": "我看到一个白色路由器..."}
  ]
}
```

### 4. 隐私模式 — LensMate 的工程亮点

| 模式 | 行为 |
|------|------|
| **正常模式** | 帧和对话存储在内存，会话结束后丢弃 |
| **隐私模式** | 前端 ON：摄像头画面实时模糊人脸；后端 ON：不存储任何帧和音频，仅实时推理后丢弃 |

### 5. 成本仪表盘 — EyesChat 的可视化更优

## 成本控制策略（完整版）

### 已实现的策略

| # | 策略 | 说明 | 效果 |

| 1 | **端上语音识别** | Web Speech API（免费） | 语音识别零成本 |

| 7 | **会话 Token 预算** | 50,000 Token/会话 | 单会话上限 ~$0.25 |
| 8 | **轮次限制** | 最多 20 轮 | 进一步限制 |
| 9 | **流式响应** | stream=True | 体验优化不增成本 |
| 10 | **弱网降级** | 自动降帧率 + 分辨率 | 网络差时仍可用 |
| 11 | **实时费用展示** | Cost Dashboard | 用户可见可控 |

## 技术栈选型

| 层级 | 技术 | 选择理由 |
|------|------|---------|
| **前端** | 原生 HTML/CSS/JS SPA | 零构建，面试现场直接打开，无需 npm install |

| **通信** | WebSocket | 全双工实时通信 |
| **存储(可选)** | 七牛 Kodo | 面试展示七牛相关能力 |
