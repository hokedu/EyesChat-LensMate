# EyesChat-LensMate 演示脚本

## 场景一：启动与连接

1. 打开浏览器访问 http://127.0.0.1:8001
2. 点击"开始对话" → 状态变为"已连接"（绿点）
3. 点击 📷 打开摄像头 → 画面出现在左侧
4. 点击 🎤 打开麦克风 → 可以开始说话

## 场景二：文本对话

```
用户: 你好，介绍一下你自己
AI: 你好！我是 EyesChat-LensMate，一个AI视觉对话助手...
```

## 场景三：语音对话

对着摄像头说话，AI 自动识别并用中文朗读回复。

## 场景四：隐私模式

点击 🔒 按钮开启 → 后端停止保存数据 → 再次点击关闭

## 场景五：成本展示

底部仪表盘实时显示 Token 消耗、费用、预算使用率。

## API 配置

将 `.env.example` 复制为 `.env` 并填入 API Key:
```
OPENAI_API_KEY=你的Key
OPENAI_BASE_URL=https://api.openai.com/v1   # 或其他兼容接口
LLM_MODEL=gpt-4o
```
